# 📱 Mobile Automation Repository

🚀 Este repositorio está dedicado a la **automatización de pruebas móviles**, con el objetivo de asegurar la calidad, estabilidad y correcto funcionamiento de aplicaciones **Android** a través de pruebas automatizadas.

## 🛠️ Tecnologías y Herramientas

- ✅ **Appium**
- ✅ **Mocha**
- ✅ **Chai**

## 📂 Estructura del Proyecto

📦 mobile-automation-repo
 ┣ 📂 test              # Casos de prueba automatizados
 ┣ 📂 views              # Page Objects / Screen Objects
 ┣ 📂 utils              # Utilidades y helpers
 ┣ 📂 controls             # Configuración de entornos y capabilities
 ┣ 📂 results            # Resultados y reportes de ejecución
 ┗ 📜 README.md
